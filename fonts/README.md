# fonts/

Шрифтовая пара для подписей в рилсах (см. `../reels-style-guide.md`).

Ожидаемые файлы (положить сюда `.ttf`/`.otf`):

- `PlayfairDisplay-*.ttf` (или `.otf`) — серифный акцентный шрифт. Доступен как Google Font,
  можно скачать легально бесплатно.
- `Coolvetica*.otf` (или `.ttf`) — гротеск для плотного текста. Это не Google Font и не
  распространяется через открытые реестры (npm/pypi/apt) — нужен файл шрифта от пользователя
  (лицензионная копия).

Пока файлы не загружены сюда, при монтаже используется ближайший системный аналог
(например Liberation Sans) как временная замена.
