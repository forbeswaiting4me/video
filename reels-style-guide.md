# Reels — стиль подписей (постоянное правило)

Применять на всех последующих рилсах, которые монтируются в этом репозитории через `video-use`,
если пользователь явно не попросит иначе.

## Текст / субтитры

- **Без обводки** (no outline / no stroke on the text). Для контраста на светлом/пёстром фоне
  использовать полупрозрачную подложку или мягкую тень вместо обводки, если нужна читаемость.
- **Шрифтовая пара**: `Playfair Display` (серифный, для акцентов/заголовочных слов) +
  `Coolvetica` (гротеск, для основного текста). Использовать вместе как пару, когда текста
  много одновременно (несколько строк/фраз в кадре) — Coolvetica для плотного текста,
  Playfair Display для смыслового акцента.
- Файлы шрифтов лежат в `fonts/` в корне репозитория (см. `fonts/README.md`) — устанавливать
  их per-render через `fontconfig`/`fc-cache` или передавать путь напрямую в фильтр `ass`/`drawtext`.
- **Позиция текста — выше**, чем стандартный низ кадра: не прижимать к нижнему краю, поднимать
  над зоной, где соцсети (Reels/TikTok/Shorts) перекрывают видео своим UI (иконки, подпись,
  музыка, кнопки) после публикации. Ориентир: не ниже ~30–35% высоты кадра от низа (margin
  заметно больше дефолтного).
- Цвет текста — уточнять per-видео (не единое правило); последний запрошенный цвет: жёлтый.
